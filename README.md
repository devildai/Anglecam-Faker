## 🌟 Overview

AngleCam Studio is a browser tool designed to produce realistic photo overlays featuring comprehensive geographic and orientation telemetry. Whether you are generating sample datasets, testing field inspection formats, or editing captured photo notes, AngleCam Studio gives you control over every field.

---

## ⚡ Features

- 📍 **Interactive Map Picker** — Click anywhere on the Leaflet map to set your latitude and longitude.
- 📐 **Full Telemetry Customization** — Configure altitude, pitch, roll, compass bearing/azimuth, and accuracy readings.
- 🔠 **OCR Text Detection** — Extract metadata automatically from reference photos using Tesseract.js.
- ✂️ **Built-in Image Cropper** — Crop and frame your shots before overlaying telemetry.
- 🕒 **Custom Date & Time** — Timestamp formatting matching official engineering survey outputs.
- 💾 **High-Resolution Export** — Render canvas exports directly to PNG/JPEG in full quality.

## 🚀 Quick Start

Open index.html in your browser:

``bash
git clone https://github.com/devildai/Anglecam-Faker.git
cd Anglecam-Faker
start index.html
``

## 🛠️ Technologies Used

- **Leaflet.js** — Geospatial map controls & geocoding
- **Tesseract.js** — OCR text extraction
- **Cropper.js** — Interactive image transformation
- **HTML5 Canvas** — Vector and telemetry stamping
